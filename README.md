## 代码讲解
导航href="#about"等链接与section的id对应，实现页内跳转；href="#top"返回顶部。表格用colspan合并四列标题，用rowspan合并教室两行。a标签包裹img实现图片跳转，所有资源使用相对路径。audio通过play和pause控制，embed嵌入MP4并保留video备用。form中的控件放进table；同一组radio使用相同name，JavaScript阻止默认提交、检查日期与邮箱等，再显示明确的演示结果。
